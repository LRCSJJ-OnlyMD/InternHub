🎯 Project Overview

What is InternHub?

InternHub is a comprehensive internship management platform designed to streamline the entire internship lifecycle for educational institutions.

Problem Solved

  • Manual internship tracking is time-consuming
  • Lack of centralized document management
  • Poor communication between stakeholders
  • No real-time status updates

Target Users

👨‍🎓

Students

Submit and track internship applications

👨‍🏫

Instructors

Supervise and validate internships

👨‍💼

Administrators

Manage users, sectors, and oversee system

🔐 Security Implementation

Authentication Flow

1. User submits credentials ↓ 2. Server validates & generates JWT ↓ 3. JWT stored in client (localStorage/SecureStorage) ↓ 4. JWT sent in Authorization header ↓ 5. Server validates JWT on each request ↓ 6. Access granted/denied

Security Features

🔑 JWT Authentication
🛡️ Role-Based Access Control
📱 Two-Factor Auth (2FA)
✉️ Email Verification
🔒 Password Encryption (BCrypt)
🚫 CORS Configuration

🔌 RESTful API Design

Endpoint Method Description Auth
/api/auth/login POST User authentication Public
/api/internships GET List internships JWT
/api/internships/{id}/validate PUT Validate internship INSTRUCTOR
/api/admin/users GET Manage users ADMIN
/api/chat/conversations GET Get chat conversations JWT
/api/library/documents POST Upload to library JWT

Response Format

{ "success": true, "data": { ... }, "message": "Operation successful", "timestamp": "2026-01-16T12:00:00Z" }

Error Handling

{ "success": false, "error": "VALIDATION_ERROR", "message": "Invalid input data", "details": ["Field 'email' is required"] }

🧩 Challenges & Solutions

Technical Challenges

Challenge 1: Java 25 Compatibility

Lombok library incompatibility with latest Java

✅ Solution: Upgraded to Lombok edge-SNAPSHOT

Challenge 2: Real-time Communication

Implementing cross-platform WebSocket

✅ Solution: STOMP protocol with SockJS fallback

Challenge 3: File Storage

Secure cloud storage for documents

✅ Solution: Cloudinary integration with signed URLs
